Pipeline Engineering Roadmap

Technical progression from naive dense retrieval to production-grade query decomposition

1

Dense Vector Baseline

MiniLM-L6 vector embeddings stored in ChromaDB. Evaluates single-hop semantic similarity at k=4.

2

Hybrid BM25 + RRF

Combines sparse lexical tokens with dense vectors using Reciprocal Rank Fusion constant k=60.

3

Joint Cross-Encoder

Full cross-attention scoring with ms-marco-MiniLM-L-6-v2 on top 15 candidate passages down to top 4.

4

Multi-Query Decomposition

Deconstructs multi-clause inquiries into sub-queries, executes parallel retrieval, and synthesizes answers.
